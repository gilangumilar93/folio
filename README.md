# Folio

A quiet markdown notes desk. The list sits beside the page, and every note stays in this browser.

## Run

```bash
npm install
npm run dev
```

Then open [http://localhost:8080](http://localhost:8080).

## Use

- The first line of a note is its title.
- Search filters the list as you type.
- Preview sets the markdown in type. Edit returns to the page.
- Delete asks once, then removes the note.

On a keyboard: Ctrl or ⌘ N makes a note, K searches, \ toggles preview, Alt with the arrow keys moves between notes, and Backspace deletes (press twice).
